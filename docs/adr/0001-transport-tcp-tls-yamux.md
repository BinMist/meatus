# ADR 0001：默认传输采用 TCP + TLS 1.3 + yamux

- 状态：已接受（D3）
- 日期：2026-11-16
- 决策者：项目负责人

## 背景

Meatus 需要在企业内网、家庭宽带和云主机之间建立稳定隧道。候选方案是 TCP+TLS+yamux 与 QUIC（quinn）。国内网络对 UDP 的 QoS、企业网对 UDP 的封禁、以及排障工具的成熟度，都会直接影响可用性。

## 决策

默认且唯一的 v0.x 传输是 **TCP + TLS 1.3 + yamux**：

- 控制连接与数据连接都走 TLS 1.3，证书校验默认开启，可 pin 服务端公钥。
- 一条 TLS 连接上复用多条 yamux stream，每个用户连接占用一个 stream。
- QUIC 仅作为 v2（M8）的可选项，不进入 v0.5 的验收路径。

## 代价

- yamux 共享底层 TCP，单条连接内存在队头阻塞；大流量并发场景需要多连接池，M1 只做单连接 + 限流。
- TLS 握手与证书管理比裸 TCP 复杂，证书链路在 M3 单独投入。

## 备选方案

| 方案 | 放弃原因 |
|------|----------|
| QUIC 作为默认 | UDP 在国内常被 QoS / 封禁，企业网失败率高；排障工具少 |
| 裸 TCP + 自研加密 | 需要自己维护密码学与协议，风险与成本都更高 |
| WireGuard 类 VPN | 不是“把单个端口暴露出去”的产品形态，权限粒度太粗 |
